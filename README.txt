SAVIOR STORE — VERSÃO ACADÉMICA DEMONSTRATIVA

COMO ABRIR NO ACODE
1. Extraia o ZIP para uma pasta do telemóvel.
2. No Acode, escolha Open Folder / Abrir pasta.
3. Abra a pasta SaviorStore_ACODE.
4. Abra loja.html e escolha Preview para iniciar pela apresentação pública.
5. Use os botões Entrar / Criar conta para abrir index.html.

PÁGINAS E ESTRUTURA
- loja.html: apresentação pública, categorias, produtos em destaque e explicação da revenda.
- index.html: autenticação e criação de conta de revendedor.
- admin/dashboard.html: painel do administrador, gestão de produtos, pedidos, revendedores e perfil.
- revendedor/: dashboard, catálogo, criação e histórico de pedidos, notificações, suporte e perfil.
- css/style.css: estilos e adaptação para telemóvel/computador.
- js/data.js: dados iniciais e armazenamento local.
- js/auth.js: autenticação demonstrativa.
- js/admin.js: operações administrativas.
- js/reseller.js: funcionalidades do revendedor.

CONTAS PARA DEMONSTRAÇÃO
Administrador: admin / admin123
Revendedor: revendedor / revendedor123

FUNCIONAMENTO E LIMITAÇÕES
Esta versão é um protótipo académico front-end feito com HTML, CSS e JavaScript. Os dados são guardados no localStorage do navegador e ficam neste dispositivo/navegador. Não existe ainda servidor, base de dados central, pagamentos reais, envio de mensagens ou sincronização entre dispositivos. As credenciais de demonstração não devem ser usadas como segurança de uma loja em produção.

IMAGENS
As fotografias de demonstração são carregadas de URLs externos. É necessária ligação à Internet para as visualizar. O administrador também pode adicionar produtos com uma URL de imagem.

PARA APRESENTAR
Comece em loja.html, explique o modelo de revenda, crie/entre numa conta de revendedor e demonstre um pedido. Depois entre como administrador para mostrar a gestão do catálogo e dos pedidos.
